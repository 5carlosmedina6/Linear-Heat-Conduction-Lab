# Linear Heat Conduction Lab

MATLAB project for analyzing linear heat conduction through a brass bar using the TecQuipment TD1002A apparatus.

## Features
- Temperature profile visualization at different measurement times.
- Linear regression and coefficient of determination (\(R^2\)).
- Experimental thermal conductivity calculation.
- Comparison with reference thermal conductivity values for brass.

## Tools
- MATLAB
- Experimental data from the TD1002A heat conduction experiment.

## Experimental Results
- Thermal conductivity: 133.12 W·m⁻¹·K⁻¹
- Reference value for brass: 109–125 W·m⁻¹·K⁻¹
- Measurement times: 2 s and 180 s.

## Usage
Open `` in MATLAB and run the script to generate the temperature plots and calculate thermal conductivity.
